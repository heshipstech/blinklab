ADVERSARIAL TESTING OF THE ROUND II RULES
=========================================

Written 27 August 2026, after the rules merged and before any round
II session exists — the plan says this pass is owed BEFORE the first
real file is opened, on synthetic files only. The tool under test is
the round II path added to the reader:

    analysis/blinklab/round2.py
    analysis/tools/validation_report.py   (the --rules round2 branch)

The round I paths were attacked on 20 August
(docs/validation-tool-adversarial.txt) and are not re-attacked here;
these probes aim only at what the new rules added. Every hostile
file lives in a throwaway folder outside the repository.

THE RULE THIS DOCUMENT FOLLOWS, unchanged from round I: every
prediction below is committed before its probe is run — this
predictions section is committed on its own, and the outcomes are a
later commit — and a prediction that turns out wrong stays in the
record, wrong. Severity classes as before: SILENT WRONG RESULT,
WHOLE-TABLE CRASH, MISLEADING REFUSAL, COSMETIC. One addition for
this pass: CORRECT, a probe whose predicted behaviour is the right
one, run to prove the defence exists rather than to find a hole.

THE PROBES, EACH WITH ITS PREDICTION
------------------------------------

Probe A. A session whose metadata reads `calibration_refused: True`,
capital T — the exporter writes only lowercase, so this is a
hand-edited or transformed file.
  PREDICTION: SILENT WRONG RESULT. The reader compares against the
  lowercase string, so True is not true, the refusal is not seen,
  and the session is scored as an ordinary participant — ruler
  columns and all — with nothing anywhere saying its calibration
  was refused.

Probe B. A session whose metadata reads `sampled_fps: NaN` — the
browser's toFixed prints NaN if a rate computation ever goes wrong,
so this is a plausible damaged export.
  PREDICTION: SILENT WRONG RESULT. Python's float("NaN") parses, so
  the evidence rate becomes nan; nan compared below the 25 floor is
  False, so the session is treated as sound evidence, and the rules
  line prints the word nan as if it were a measurement.

Probe C. An otherwise healthy session with NO marks at all, read
under --rules round2.
  PREDICTION: MISLEADING (a wrong sentence, not a wrong verdict).
  With no marked window the windowed frame is empty, zero distinct
  baseline values counts as not-a-defect, and the rules line prints
  "baseline constant across the marked window" for a session that
  has no marked window to be constant across.

Probe D. Marks reversed: marker_1 at 12 s, marker_2 at 2 s.
  PREDICTION: MISLEADING, same sentence as probe C. The window mask
  selects nothing, so the freeze line asserts constancy over an
  empty window, and the evidence fallback quietly finds no rows and
  prints a dash without saying the window was backwards.

Probe E. A refused session whose `calibration_spread_ratio` cell is
the word junk.
  PREDICTION: CORRECT. The number reader returns None for a
  non-number, the certificate prints a dash for the spread, and the
  refusal is still counted with its sample count intact.

Probe F. A folder whose only session is refused, read under
--rules round2.
  PREDICTION: CORRECT. The refusal is counted first, the checks
  table prints "no readable sessions", the rules section prints "no
  scoreable sessions", and the exit code is zero — a refused
  calibration is a result the round can carry, not a reader failure.

WHAT HAPPENS NEXT. The probes run against a build of the merged
rules, each outcome is appended below as a dated section, every
finding of MISLEADING or worse gets a failing test before its fix,
and the fixes land in the same increment as this document's
outcomes commit.

THE OUTCOMES, 27 August 2026, appended after the probes ran
------------------------------------------------------------

Probe A: CONFIRMED, silent wrong result. The capitalized flag was
read as not-true and the refused session was scored as an ordinary
participant, ruler columns and all. FIXED: the flag reader accepts
only the two strings the exporter writes; any other value raises a
loud refusal naming the key and the value, the pair lands in the
REFUSED section, and the exit code is nonzero. The same strictness
covers calibration_ceiling_bound on a refused session, so a damaged
ceiling flag is a damaged file, not an INSTRUMENT DEFECT line — that
line is reserved for a file that legibly says refused-but-unbound.

Probe B: CONFIRMED, silent wrong result. float("NaN") parsed, nan
compared below no floor, and the rules line printed the word nan as
sound evidence. FIXED: a non-finite metadata number reads as absent,
so a damaged sampled_fps falls back to the per-second fps column
over the marked window, with the fallback named in the output.

Probe C: CONFIRMED, misleading. "baseline constant across the marked
window" printed for a session with no marks. FIXED: the freeze
verdict is three-valued now, and a session with no marked window
prints "no marked window to judge the freeze" instead of asserting
constancy over nothing.

Probe D: PREDICTION WRONG, and the record keeps it. The reversed
markers never reached the round II rules: the round I reader refuses
them one layer down ("numbered in one order and timed in another"),
exit 1. The defence predicted missing already existed. The
misleading sentence this probe predicted was real, but only probe
C's route (no marks at all) could reach it.

Probe E: CONFIRMED CORRECT. The junk spread ratio printed as a dash
and the refusal was counted with its sample count intact.

Probe F: CONFIRMED CORRECT. Refusal counted first, empty tables
honest, rules section says "no scoreable sessions", exit 0 — a
refused calibration is a result, not a reader failure.

Each fix had its test watched failing against the merged rules
before the fix landed; the four tests live in
tests/test_round2.py under TestWhatTheAdversarialPassFound. The
score for the pass: two silent wrong results and one misleading
sentence found and fixed, one prediction wrong in the good
direction, two defences proven. The round II rules are now cleared
for the first real file, whenever the owner schedules the round.
