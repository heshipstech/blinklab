- [x] **Node — three different majors on one machine.** 22, 24 and 26. Nothing
      is wrong with any of them individually; the cost is that "run `nvm use`
      and work" gives a different runtime per repo, so a habit formed in one is
      wrong in the next. Worth one deliberate choice rather than three
      accidents.
- [x] **Package manager — the split is real and it bit tonight.** besight.io
      uses pnpm by ruling; the other two use npm. During this audit an agent ran
      pnpm with the wrong working directory and left `pnpm-lock.yaml` and
      `pnpm-workspace.yaml` in the **portfolio**, which is npm-only by ruling
      Q4. Untracked, caught, removed. The divergence is defensible per repo; it
      is worth knowing it has a failure mode.
- [x] **Linter — the portfolio has none**, while both siblings run eslint. Its
      1,370 LOC of build scripts have neither linting nor, with
      `checkJs: false`, type checking.
- [x] **`.gitignore` baseline — consistent.** All three cover `node_modules`,
      `dist`, `.env` and `.DS_Store`. Sizes differ (10 / 32 / 67 lines) because
      the stacks differ, not because anything is missing.

      declares MIT in both LICENSE and `package.json`. The portfolio is public
      with neither, so it is all-rights-reserved by omission rather than by
      decision. besight.io is private, so nothing is owed there.
